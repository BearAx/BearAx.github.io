# Aleksandr Medvedev - ML Research & Systems Portfolio

Personal CV and project portfolio for Aleksandr Medvedev, focused on model
quality, reproducible experiments, and efficient PyTorch systems.

Live site: [medvax-ai.github.io](https://medvax-ai.github.io)

## Local development

```bash
npm install
npm run build:pages
```

The static export is written to `out/`. Pushes to `main` are published through
the GitHub Pages workflow.
